# Co-pilot 小型知识检索（2026-10-07）

## 范围

现有 `/v1/chat` 接入 `src/agent/knowledge.py` 中四条版本化产品口径：订单销售额、利润数据边界、复购/召回适用条件、ROI 实验证据。
知识为公开产品方法，不是外部政策或已验证的商家事实。来源有稳定 ID、版本、原文及代码出处；不伪造不存在的公开链接。

## 使用路径

- 登录后问“复购率是什么意思”“ROI 如何计算”：确定性检索并展示原文及来源，不查询订单，不调用模型。
- 问“我的店利润如何”：保留原有账户限定的数据查询，将匹配规则注入分析与策略步骤；答复单独列出方法原文，不能当成店铺事实。
- 问“什么是美国关税政策”：没有匹配知识，明确无法据此作答，不虚构实时政策。
- 数据查询失败或诊断明确不足：不输出可执行策略。

登录与共享配额检查保持原样；即使纯知识回答不调用模型，仍占用现有问答额度以限制滥用。
没有新增向量服务、依赖、数据库表、抓取任务；不索引商家文档、客户数据、订单明细或历史对话。

## 验收与边界

合成数据测试覆盖中英检索、最多三条、未知问题拒答、认证/额度保留、账户参数不能覆盖、原文来源、提示词传递及数据不足策略拦截。
原文显示是检索证据，不等于已经验证模型的每条经营建议在语义上得到它支持。正式采用前应继续评估建议支持率和用户核对时间。
首版按关键词检索，不保证所有同义词、否定句或复杂追问均命中；未匹配不会调用私有文档检索。
