# AI 电商运营智能系统演示说明

## 主演示入口

打开：

```text
D:/olist_project/dashboard/ai_operations_system.html
```

这个页面是动态系统，不是普通截图式看板。左侧可以切换地区、客户分层、月份和活动预算；右侧会实时更新经营指标、趋势图、客户分层、AI 运营诊断、活动模拟和面试讲解提示。

## 面试时怎么说

开场：

“我把原来的 Olist 电商分析项目升级成了一个 AI 电商运营智能系统。它的逻辑不是只展示图表，而是从原始订单数据出发，经过 Python 自动清洗、聚合和客户分层，再由本地 AI 运营分析引擎生成动态诊断和策略建议。”

展示左侧筛选器：

“这里可以切换地区、客户分层和时间范围。每次切换后，系统会实时重算订单数、销售额、客单价，并刷新对应的趋势和策略。”

展示 AI 运营诊断：

“这块是系统的智能分析结果。它会根据当前筛选口径判断经营表现、支付结构和重点客群，再输出运营动作，而不是让我手动读图。”

展示活动模拟器：

“运营不只是看数据，还要做动作。所以我加了活动模拟器。选择不同客群和预算后，系统会估算新增订单和销售拉动，并给出对应触达话术。”

讲技术实现：

“技术上，我把它拆成数据清洗/分析建模层和 Agent 展示层：`src/data_cleaning.py` 负责生成事实数据，`src/analysis_rfm.py`、`src/model_clustering.py` 等负责分析建模，`src/agent/agent_graph.py` 负责理解问题、调用确定性工具并生成运营建议。这样后续可以很容易接入真实店铺 API 或大模型 API。”

收尾：

“如果放到真实业务里，这个系统可以每天自动更新，生成运营日报、活动复盘和客户触达建议。后续接入大模型后，还可以自动生成私域文案、优惠券策略和差评原因分析。”
