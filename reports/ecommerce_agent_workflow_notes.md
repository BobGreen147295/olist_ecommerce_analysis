# AI 电商运营智能体工作流说明

## 工作流目标

这个工作流面向电商运营场景，根据订单、支付、地区、RFM 客户分层和用户聚类等指标，自动生成经营诊断、运营建议和行动优先级。

## 智能体分工

1. 经营监控智能体
   - 关注销售额、订单数、客单价和月度波动。
   - 判断当前是增长、稳定还是下滑。

2. 客户分层智能体
   - 读取 RFM 客户分层。
   - 给出高价值、潜在高价值、一般价值、低价值客户的运营策略。

3. 地区增长智能体
   - 分析各州销售额和 TOP 地区集中度。
   - 给出地区投放、活动资源和仓配优先级建议。

4. 支付转化智能体
   - 分析支付方式占比、支付金额和分期期数。
   - 给出支付优惠、分期免息和转化优化建议。

5. 活动策略智能体
   - 根据客户池和客单价估算活动潜力。
   - 输出可执行的活动方案。

6. 运营总监智能体
   - 汇总所有智能体诊断。
   - 按 P0/P1/P2 优先级输出行动清单。

## 运行方式

在 `D:/olist_project` 目录下运行：

```bash
.venv\Scripts\python.exe src\agent\run_agent.py "分析最近半年的销售趋势"
```

运行后会生成：

```text
reports/agent_workflow_report.md
reports/agent_workflow_result.json
```

## 面试时怎么讲

“我在项目里加入了一个多智能体工作流。它不是一个单独的规则判断，而是把电商运营拆成经营监控、客户分层、地区增长、支付转化、活动策略五个智能体。每个智能体读取对应数据指标，给出证据、建议和下一步动作。最后由运营总监智能体汇总成优先级行动清单。”
